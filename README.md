# CIRCALL methylomics

Project repository for CIRCALL methylomics, including PAT, UXM, EpiDISH, DecoNFlow and DMRcate workflows.

Publication is in progress. This repository currently contains this README only; the prepared project snapshot has not yet been uploaded.

The preprocessing pipeline is maintained separately in [methylseq_AH](https://github.com/ahhout/methylseq_AH). Earlier project history and existing results remain in their original HPC locations.
